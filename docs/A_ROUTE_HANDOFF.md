# A 同学任务单 · 福田积水绕行

第一轮请交付一个能在福田研究区选取任意两个**路网节点**、按指定情景和时刻求绕行路线的可复现样例。先完成地面机动车道路；把暂时无法核验的桥、隧道、转向或封路情况写入覆盖说明。B 负责地图选点、路线绘制、时间轴和结果面板。

## 可直接复用的资料

- 课程源仓库的 `data/raw/osm_raw.json` 含道路节点 ID、折线和部分通行标签。网站的 `vectors.json` 可用于绘制底图，路网连通性请从原始节点 ID 构建。
- 网站的 `system/public/data/meta.json` 描述福田范围和本地坐标。三套情景位于同目录的 `scenarios/`，各有 49 帧，0 到 480 分钟、每 10 分钟一帧。
- 每帧的 `depth` 是 Base64 编码的 192 × 136 字节数组。按行由北向南、每行由西向东读取，1 表示 1 cm，255 表示 255 cm 或以上。约 32 m 的地表网格水深与车道路面实测水深有区别。
- B 已交付三组固定起终点、10/15/30 cm 三档演示阈值和三套情景的绕行对比。生成器和产物分别在 `scripts/build-route-candidates.py` 和 `system/public/data/route-candidates.json`。扩展研究区、情景或阈值后要重新生成候选集。

## 第一轮交付给 B 的数据和模型

下列文件名是建议的接口约定。可以用 Python、GIS 或其他工具离线生成，浏览器只需读取静态结果。

| 交付物 | 内容与约定 | 用途 |
| --- | --- | --- |
| `network.geojson`、`turns.json` | 有向路段提供稳定的 `edgeId`、`from`、`to`、道路名、长度（米）、WGS84 折线、通行方向、桥隧及层级；转向表给出进入路段、经过节点、离开路段和限制类型。附采集时间、来源和许可 | 支持任意路口选点，避免逆行、非法转弯和立交错误连通。原始归档缺少转向限制关系，优先补查 |
| `edge-depth/<scenarioId>.json` | 以路段 ID 与情景分钟数为键，输出路面最大水深（cm）、质量标记、有效数据覆盖率。缺测用 `null`。附坐标转换、网格大小、时间基准、模型版本和路段采样方法 | 把水深与道路相交。注明桥面/地面/下穿所用高程与水位基准。资料不足的层级标为未知 |
| `rules.json` 与路段判定函数 | 列明适用交通方式、阈值单位、比较符号、未知值处理、规则出处及验证状态。有封闭记录时附路段、起止时间与来源 | 为指定时刻生成可用路段集合。演示中水深达到阈值即排除；封闭或水深未知的路段不能作为已核验候选 |
| 求路脚本、输入样例与 `routes-expected.json` | 输入起终点、情景、分钟、阈值。输出常规路线和避水路线的有序路段 ID、长度、最高水深和状态。无路时用 `no_route`，资料不足时说明 `insufficient_data` | 用 Dijkstra 或 A* 在有向图上求最短距离；处理转向限制时保留上一条路段。先算常规线，再叠加水深与封路约束重算。两次求路均遵守交通方向和转向 |
| 核验表与复现命令 | 记录资料来源、日期、使用许可、已覆盖路段数、缺测比例、已知误差和样例输出。有带位置与时间的积水实测、交通封闭或恢复记录时，单独提供对照 | 让 B 能复算结果，并在页面准确区分模型估计、实测记录和资料缺口 |

如果暂时拿不到桥面高程、隧道排水或已核验的转向关系，先交付注明覆盖范围的地面子图。第一轮可直接复用现有水文情景，无需重新训练模型。要提高水深可信度，再补沿线路面高程、排水设施、积水观测位置与时间，并报告校核误差。

## 联调与验收

1. 用相同起终点、`replay-2309` 和 15 cm 阈值复现当前样例。红荔路片区在第 0 分钟两线重合；第 240 分钟常规线 794.6 m、最高 47 cm，避水线 1065.0 m、最高 5 cm。福华三路片区第 360 分钟没有符合条件的候选线。这些数值用于对齐现版本；若新版路网或高程改变结果，附上发生变化的路段和原因。
2. 另选一对当前面板未预设的节点，输出起终点与连续路段序列；证明可从新输入求路。用单行道反向、禁转和相交但分层的道路分别检查拓扑。
3. 构造路段水深恰等于阈值、缺测和有效封闭三种样例。切换时刻后重新判断；封路、不可达、资料不足均有可区分的结果。未知数据不能按 0 cm 参与计算。
4. 将离线输入、生成命令、输出和规则版本一起交给 B。浏览器已接入的演示按当前单帧水深计算，沿途未来水深不在这轮模型范围内。

## 可以接着做的功能

| 功能 | A 需要新增的输入 | A 交付的模型结果 |
| --- | --- | --- |
| 可达避险点推荐 | 核验后的避险点入口、开放时段、可用容量、入口对应的路网节点；若用于步行则补人行道、过街连接和步行适用规则 | 在对应交通方式的路网上计算可达设施，返回可达入口、路线、距离及不可达原因 |
| 出发时间和通行时间比较 | 分路段基础速度、带时间戳的速度观测、经校验的积水减速关系、逐时封闭与预报水深 | 按车辆预计到达各路段的时刻判断通行，返回预计时长、暴露时段和数据不确定性 |

这两项可等第一轮数据验收后独立开发。面向公众提供实际出行建议，还需要更新及时的封路信息、当地适用的通行规则和路面水深验证。
