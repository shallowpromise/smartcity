# 给 A 的小功能 · 同一场雨，绿地和道路各产生多少径流

把一张小对比卡放在左侧「水深解读」展开区。用户选择一场累计降雨 50、100 或 200 mm，看相同雨量落在绿地和道路上，各有多少变成地表径流。默认选 100 mm。这是独立的教学试算，选项只更新这张卡。

## 需要交付

- 一个纯函数，输入累计雨量（mm）与曲线数 CN，返回累计直接径流（mm）。沿用项目地表参数，绿地 CN 58、道路 CN 96。
- 两条标明数值的横条，分别表示绿地和道路的累计径流。两条使用同一把尺，满量程为选中的累计降雨。余量标为「下渗、截留等综合损失」；径流与损失均按一位小数显示。
- 在卡片下方说明「地块产流深按单位面积折算。计算某处路面积水还需要地形汇流和排水。」雨量切换支持键盘操作。

## 算法与验收

按课程模型，令 S = 25400 / CN − 254（mm），初损取 0.2S。累计降雨 P ≤ 0.2S 时，径流 Q = 0；超过初损后，Q = (P − 0.2S)² / (P + 0.8S)。综合损失等于 P − Q。[HEC-HMS 技术手册](https://www.hec.usace.army.mil/confluence/hmsdocs/hmstrm/canopy-surface-infiltration-and-runoff-volume/infiltration/scs-curve-number-loss-model)

| 输入 | 预期结果 |
| --- | --- |
| P = 0 mm | 两类地表的径流均为 0 mm |
| P = 100 mm，绿地 | 径流 16.2 mm，综合损失 83.8 mm |
| P = 100 mm，道路 | 径流 88.3 mm，综合损失 11.7 mm |
| 切换三个雨量档位 | 横条和数字同步更新；时间轴、告警和绕行结果继续使用当前情景数据 |
